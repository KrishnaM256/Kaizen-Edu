# 📚 Eduzen – AI-Powered Learning Management System (LMS)

Eduzen is a powerful MERN-stack based Learning Management System developed for QUASAR 3.0 Hackathon. It aims to revolutionize modern education by combining smart automation, AI-driven assessments, and community-based learning.

> 💡 Project by Team **Kaizen** | PS No: **PS12** | College: **VIT, Pune**

---

## 🔧 Project Structure

```
Kaizen/
├── backend        # Node.js + Express API for handling core LMS logic
├── frontend       # React.js application for students, mentors, and admins
└── flask          # Python Flask module for AI-based assessment (Quasar3.py)
```

---

## 🚀 Getting Started

Follow these steps to get the project running locally:

### 1. Backend – Node.js

```bash
cd backend
npm install
npm start
```

Starts the backend server using Express.js.

---

### 2. Frontend – React

```bash
cd frontend
npm install
npm run dev
```

Starts the React frontend using Vite (usually available at http://localhost:5173).

---

### 3. Flask – AI Assessment Engine

```bash
cd flask
python Quasar3.py
```

Runs the AI-based assessment engine which handles:
- OCR and Regex-based answer extraction
- Answer scoring and feedback using NLP
- Contextual question understanding and scoring

## ✨ Features

### 👨‍🏫 For Teachers / Mentors
- Effortless classroom and timetable management
- Multimedia content delivery
- Performance analytics dashboards

### 🎓 For Students
- AI-based handwritten and digital assignment evaluation

- Quick revision and self-study modules

- Schedule optimization and performance insights
